
# Summing and Difference Amplifiers - Engineering Workshop Report

This repository contains the IEEE-formatted LaTeX source code, compiled PDF report, and experimental data for an undergraduate electronics workshop focusing on operational amplifiers (**LM741**) and data acquisition using the **NI myDAQ** platform.

---

## 🚀 Project Overview
Operational amplifiers are foundational components in analog circuit design for signal conditioning and arithmetic computations. This project covers the theoretical design, practical implementation, and experimental validation of two core op-amp configurations:
1. **Weighted Summing Amplifier:** Evaluated across multiple input combinations and resistor values.
2. **Difference Amplifier:** Configured to process complementary AC signals and verify common-mode rejection and differential gain.
